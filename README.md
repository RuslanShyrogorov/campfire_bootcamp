# React + TypeScript + Vite

## Project Setup & Running

### Install dependencies

```bash
npm install
```

### Run the project
To start both the frontend and the local API server simultaneously:

```bash
npm run start
```

This command starts:
* Vite — frontend application
* json-server — local mock API on port 3001

The frontend will be available at: http://localhost:5173
The API server will be available at:http://localhost:3001

### Run servers separately
If needed, you can start each server separately:

```bash
npm run dev
```
Starts the Vite development server.

```bash
npm run server
```
Starts the json-server mock API.
